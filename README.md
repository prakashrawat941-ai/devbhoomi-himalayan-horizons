# Devbhoomi Himalayan Horizons

Build a complete, mobile-first travel platform named Devbhoomi Himalayan Horizons, with the tagline “Live a little deeper.”

Choose the best modern UI/UX, colors, typography, responsive design, and architecture. Make it premium, fast, and app-like on Android.

Frontend: Home, Explore Hidden Villages, Village Homestays, Uttarakhand Culture, Aipan Art, Nanda Devi Raj Jat, Golju Devta, Dana Holi, local Holi traditions, Trip Planner, Workation, Contact, Login and Registration.

Backend: Use Supabase for database, authentication, secure APIs, image storage, and Row-Level Security (RLS).

Roles & onboarding: Customer, Homestay Partner, Driver, and Admin. Create separate registration/onboarding flows, role-based dashboards, profile management, and admin approval for partners and drivers.

Admin panel: Manage users, villages, homestays, cultural content, trip enquiries, cab requests, partner approvals, and reports.

Cab booking: Only Delhi–Almora and Chandigarh–Almora. Do not invent live prices, availability, or confirmed bookings.

Trip planner: Itineraries, estimated budgets, saved plans, and enquiry submission.

Build a working MVP in small, testable stages. Connect frontend and backend properly, secure all data, validate forms, handle errors, and test major flows. Never expose secret keys or claim incomplete features are working. If credentials or manual setup are required, explain the exact steps.
